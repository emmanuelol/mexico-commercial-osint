# License Compliance & Data Separation

## 1. INEGI DENUE (Términos de Libre Uso MX)
Data from the Directorio Estadístico Nacional de Unidades Económicas (DENUE) is published by INEGI under Libre Uso MX. It allows reuse, adaptation, and commercial exploitation, provided proper citation is maintained:
> Fuente: INEGI. Directorio Estadístico Nacional de Unidades Económicas (DENUE).

## 2. OpenStreetMap (ODbL) Horizontal Separation
When OpenStreetMap POI data is consumed:
- To comply with the Open Database License (ODbL), any derived database combining OSM data must respect share-alike conditions.
- To avoid license contagion, DENUE records and OSM records are kept horizontally separate as independent layers joined only via non-derivative spatial queries or reference keys.
